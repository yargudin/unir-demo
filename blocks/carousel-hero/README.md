# carousel-hero

Custom **carousel** block. Purpose: full-width rotating promo slider: text panel beside a photo, dot navigation, autoplay.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide. Cell 1: image (alone in the cell). Cell 2: heading (H2), description paragraph, optional CTA link. Cell order may be swapped; the image cell is detected. Slides rotate every 6 s (paused on hover/focus and with reduced motion); with one row no dots are shown.

## Supported variations

No variations.

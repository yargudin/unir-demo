# cards-featured

Custom **cards** block. Purpose: featured promo grid: one tall image card plus compact text cards with an uppercase CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card. Cell 1: image (optional; a card with an image spans two grid rows). Cell 2: title (H3) and a CTA link in its own paragraph (the last link-only paragraph becomes the CTA).

## Supported variations

No variations.

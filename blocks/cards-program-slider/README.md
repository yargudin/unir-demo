# cards-program-slider

Custom **cards** block. Purpose: horizontal slider of program cards with prev/next arrows and area filter chips built from each card's area.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per program. Cell 1: image. Cell 2: eyebrow paragraph (e.g. "Máster Universitario en"), title (H3) linked to the program page, description paragraph, bulleted meta list (duration, ECTS, start date). Cell 3: area name, plain text (several areas separated by commas). Chips ("Todos" + each distinct area in first-seen order) appear when at least two areas exist; selecting a chip shows only that area's cards.

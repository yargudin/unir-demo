# columns-stat

Custom **columns** block. Purpose: Text column beside a big stat figure with caption, separated by a vertical rule.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row. Cell 1: H2 + paragraph. Cell 2: stat value as a paragraph (e.g. +400, not a heading) + caption paragraph. The column whose first line is number-like becomes the stat column.

## Supported variations

No variations.

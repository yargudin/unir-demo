# cards-recognition

Custom **cards** block. Purpose: 2x2 boxed cards with a ranking/press logo and a paragraph; no title, no link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card. Cell 1: logo image or icon. Cell 2: description paragraph, optional heading and CTA. Empty cells are dropped.

No variations.

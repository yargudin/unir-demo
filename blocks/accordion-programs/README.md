# accordion-programs

Custom **accordion** block. Purpose: Accordion of study areas with plus-icon rows and ruled dividers; each panel holds grouped program link lists.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per area. Cell 1: area name (e.g. Educación). Cell 2: H3 study-type subheadings, each followed by a list of program links (pretitle + title, linked). Missing cell 2 renders an empty panel.

No variations.

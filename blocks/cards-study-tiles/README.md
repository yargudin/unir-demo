# cards-study-tiles

Custom **cards** block. Purpose: row of linked study-type tiles: photo tiles with an overlaid title and arrow, plus text-only link bars stacked in one column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile. Cell 1: image (leave empty for a text-only link bar). Cell 2: the tile title as a link (heading or paragraph). Consecutive text-only rows stack together in one grid column. Links to another host open in a new tab.

No variations.

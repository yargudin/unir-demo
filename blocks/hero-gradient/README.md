# hero-gradient

Custom **hero** block. Purpose: Full-width hero: photo on the right fading into a dark left gradient, with H1, subtitle and CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: image (photo). Row 2: H1 title, subtitle paragraph, optional CTA link. Image and text may also share one row; the image is optional (dark background only).

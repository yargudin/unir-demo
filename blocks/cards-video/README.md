# cards-video

Custom **cards** block. Purpose: full-bleed video poster tiles with tint, play icon and title; plays YouTube in a modal dialog.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per video. Cell 1: poster image. Cell 2: title (heading or paragraph) and the YouTube link (watch, youtu.be, embed or shorts URL; a t= start time is kept). If the link text is the title it is kept as the visible title. Non-YouTube links stay plain links over the tile.

## Supported variations

No variations.

# cards-event

Custom **cards** block. Purpose: two-up event cards: wide banner image with a date badge overlay, tags, title, description.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per event. Cell 1: banner image. Cell 2, in order: date paragraph (e.g. "24 Nov 2026 | De 16:00 a 17:00 | Online", parts split by | or line breaks; a leading day number becomes the large figure), bulleted list of tags, title (H3) linked to the event page, description paragraph. The image links to the title link.

## Supported variations

No variations.

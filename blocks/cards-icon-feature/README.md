# cards-icon-feature

Custom **cards** block. Purpose: row of centered value-proposition items: icon, title, short text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item. Cell 1: icon (image or :icon-name:). Cell 2: title (heading or bold paragraph) and text. A single-cell row whose first paragraph is only an icon also works.

## Supported variations

No variations.

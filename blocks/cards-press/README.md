# cards-press

Custom **cards** block. Purpose: text-only press mention cards: title plus a "date - outlet" link, top border.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per mention. One cell (or two, merged): title (H3 or paragraph) and a paragraph with the "date - outlet" link to the article. The last link makes the whole card clickable; links to another host open in a new tab.

No variations.

# cards-news

Custom **cards** block. Purpose: three-column news cards: image, caption, linked title, excerpt, top border.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per article. Cell 1: image (optional). Cell 2: optional caption paragraph (before the title), title (H3) linked to the article, excerpt paragraph. The image links to the title link.

## Supported variations

No variations.
